2. 当前Bot管理员仍绑定原生Emby owner，该身份按安全规则不能通过公网播放网关；可使用已有普通cc播放账户。若要让Bot管理员也观影，需确定另绑哪个普通媒体账号，不能擅自覆盖cc已有绑定。当前媒体库无影片，真实Yamby普通账户登录、媒体播放、302长播回传和跨到期观察尚待实际媒体与客户端验证。
3. TMDB API Key和个人Bangumi授权、真实商品价格/收款渠道/二维码、广告内容、排行发布目标需管理员按运营资料配置。本轮没有替用户编造收款资料、开放商店或发生交易。
4. 真实收付款、支付平台自动退款、部分金额退款和跨站清结算不在本轮实施范围；当前为人工核款及人工退款登记，不自动转账。
