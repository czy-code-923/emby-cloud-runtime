# v0.8 · 窗口保号与会员商店

## 保号与兑换

- 每个账户按播放截止时间划分30天窗口。同一窗口只能确认A或B一次，不能撤回、切换；结算后清除旧的选择与扣分授权，下一窗口由用户重新选择。v0.7的终身锁定已迁移为窗口锁定，旧的20天切换字段仅为兼容保留，不再决定用户能否重选。
- 普通付费账户剩余严格不足30天才开放选择，Bot和Mini App显示开放时间。管理员、永久账户和有效白名单无需保号。A明确授权后按300可用积分续30天；B按服务器可信播放样本累计1800秒续30天，暂停、失联、跳播与重叠设备时间不重复计入。连续可验证的短片段也累计，不再丢弃不足两分钟的片段。
- 管理后台按UID调整单个用户的方式，或清除该用户本窗口选择；保留密码复核、审计记录和全局开关。调整一个用户不会更改其他人的方式。
- 窗口内兑换续期卡：保留剩余时长并追加卡券天数，取消旧窗口未执行的扣分授权，按新到期时间重新计算开放日。已完成结算和账本不回滚。
- 兑换付费白名单卡：白名单期限从当前时间或已有白名单截止时间中较晚者追加；普通观影剩余天数另行保留，不把它免费转成白名单天数。立即更新角色、允许线路和托管播放配额。白名单期间使用普通续期卡只增加观影期限，不增加白名单期限；到期后退回普通权限。原生Emby owner仍只负责私有管理。
- Emby暂时不可达时，卡券仍只核销一次，并明确提示权限同步中；网关按最新角色验证，后台继续重试同步。不得因提示同步中反复兑换。

## 会员商店

- 注册、续期、白名单分类，商品理由可编辑；商品支持新增、删除、上下架，删除不修改历史订单快照。显式保存空商品列表不会重新生成模板。
- 商品详情弹层选择已启用的收款渠道，管理员可同时启用多个渠道和指定默认渠道。付款方式在选购商品后显示；赞赏独立固定在商店末尾，不发会员权益。
- 支付宝口令可选上传PNG/JPEG付款截图。每张不超过2MB，每订单最多3次、每用户每分钟5次及每天12次；截图只供本人和私有后台管理员查看，禁止公网匿名查看。截图不是到账证明，不能替代真实核款。
- 管理员确认真实到账后点击“确认到账并发码”：系统取不可变订单金额，自动记录确认时间、内部核款编号，原子完成收款记录、定向单次卡码生成和通知重试。不要求再次选发卡或输入管理员密码，不再手填金额日期编号。
- 内部核款编号不是银行流水号，系统没有接入支付平台查询、自动领取口令红包、OCR核款或自动转账。管理员仍需自行领取口令红包或核实收款记录；系统不应把截图、买家自报付款当作自动到账。
- 商店配置、二维码上传及普通核款取消额外密码复核，仍要求管理员有效登录、入口隔离与CSRF意图。退款仍保留原有密码复核和来源权益保护。
- 静态收款码在私有后台使用同源预览，保持CSP图片白名单。迁移导出/导入明确包含公开收款二维码和私有付款截图，仍按命名空间与随机文件名校验，不能复制其他目录。

## 页面与资料源

- 后台按会员业务、内容、服务、系统与安全分组，合并重复导航展示，原路由和现有配置保留。
- TMDB缺失凭据返回明确的配置提示；资料源故障与网关故障分别提示，不回显密钥或上游私网地址。v3 API Key和API Read Access Token沿用同一设置字段，见[TMDB官方认证说明](https://developer.themoviedb.org/docs/authentication-application)。
- Bot默认横图更换为2:1安全留白版本。Telegram客户端控制消息图片容器，无法通过网页CSS控制；新图让文字、人物与播放标记远离两侧，降低手机端裁切影响。自定义广告/自定义横图不覆盖。

## 验收边界

交易模拟使用独立临时数据库及模拟Emby端点，不向生产写虚假订单、付款或消费记录。正式发布后另记录真实站点、部署健康、TMDB检索、Bot与Mini App结果。真实收款、真实影片长播、跨到期长期观察、第二台VPS实装及自动下载追新不由上述测试替代。
