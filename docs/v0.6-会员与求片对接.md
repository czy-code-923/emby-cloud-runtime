# v0.6 会员流程、商店与求片对接

本文记录新一轮改动；正式发布和生产验收完成前不作为已上线证明。

## 商品与收款

后台商品售价、订单实收金额都按元输入，支持19.99；传输和数据库继续使用1999分，拒绝三位小数、负数、指数和越界金额，不对资金数值静默四舍五入。历史订单金额不变。

静态收款码和独立赞赏码可先选择PNG/JPEG并预览，在保存时用同一次管理员密码复核上传图片并保存配置。没有填写页面底部密码时，选图不再被禁用。图片上限2MB，后端继续验证格式、尺寸、权限、路径和MFA。上传成功但配置保存冲突时保留已上传地址供重试。

开放下单前明确提示商品价格、默认渠道、收款人/说明和静态码缺项。订单保留原收款渠道、二维码和金额快照，管理员可查看该快照并核实实际到账；不会根据用户“已付款”或截图自动发卡。

本地已验证精确金额转换、非法输入拒绝、订单二维码投影及前端类型/语言契约。真实收付款不在测试中执行。
