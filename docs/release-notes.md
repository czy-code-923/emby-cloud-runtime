v0.4.2 见微 Emby · 品牌、机器人身份与证书入口

- 应用原创“微光镜头”图标，统一见微 Emby 品牌，改善中文字体与小字号可读性。
- 修复 V2 公共接口遗漏 Bot 身份导致已配置机器人不显示；区分凭据、身份和轮询状态。
- 私聊 /start 可幂等建立普通用户身份，不授予媒体权限。Mini App 使用 Telegram 官方签名、短期独立会话、凭据防重放和 Bot 密钥轮换失效。
- 账户与独立购买域名可分别编辑；增加 Cloudflare DNS-01 证书申请、续期、定时续期状态和固定反代发布。凭据只写不回显，不占用现有 80 端口，443 冲突拒绝发布。
- HTTPS 账户入口屏蔽管理与购买 API，独立购买入口采用允许列表；SSH 管理入口保留。入口发布失败或执行器中断恢复原配置。
- Mini App 菜单在真实 HTTPS 发布后由管理员单独发布，不显示购买链接、价格或付款流程。
- 包含完整源码、镜像、校验与一键安装/卸载，支持现有面板升级。

本版本是持续实施中的基础更新，A300/B1800 保号、独立核款履约与方案其余业务尚在开发，未将这些标为完成。真实证书、网盘播放和收款验收依赖管理员提供相应配置。

v0.4.0 在来源校验回归阶段被拦截，未公开发布。v0.4.2 修正 Caddy 重复 Header 值的声明方式，并分别验证 SSH、账户和购买入口的允许来源。

临时 TLS 测试 CA 补齐关键用途扩展，以满足 Python 3.14 的严格证书验证；未关闭证书校验。镜像构建改为在完整验证通过后运行。
