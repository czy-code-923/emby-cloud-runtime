# v0.4.7 · 商店订单与会员面板

- 独立商店支持机器人一次性登录码、商品与订单、人工核款、定向单次卡码交付、未使用卡码冻结退款记录及过期卡码延长。库存、名额、到账编号和发码在同一数据库状态事务中检查。
- 后台增加商店与订单管理；核款要求管理员双重验证已启用并重新验证密码。系统仅记录核验结果，不代收或自动转账。
- 机器人按钮更新原消息，公告与收藏原生翻页，增加播放排行、媒体搜索和收藏命令；第三方客户端可继续使用命令。
- Mini App 增加公告、排行、收藏和媒体搜索；改用后台图标，并同步浏览器标签图标。公网资源白名单放行服务器图标。
- 支持 start=redeem_ 卡码链接，复用现有群组校验、容量、指定接收人和单次兑换规则；区分未开通与已开通提示。
- 增加显式域名发布维护工具，默认只读计划；执行时复用已保存 DNS 凭据和已有证书授权。

完整 30 天自动保号与可信观影结算仍在后续集成验收中，本版不将既有手动积分续期描述为该功能。

# v0.4.5 · 统一会员入口

- 机器人提供原生主面板、签到、兑换、开通、设备、线路、求片和邀请快捷命令；启动收件时发布私聊命令菜单。不支持 Mini App 的客户端仍能使用原生命令。
- Mini App 采用青绿暖金玻璃界面，增加身份验证后的权益、注册、兑换、积分续期、邀请、求片和本人在线设备；所有写入复用后端业务校验，要求同源意图头。
- 后台配置可控制顶部推广位及独立商店按钮；新增网页仅管理员登录开关，旧普通网页会话同时失效。升级已有部署不擅自覆盖现有配置。
- 修复新版线路接口遗漏到期与角色检查、未绑定用户可能看到无所属会话的问题。
- 此版本不宣称独立商店核款、完整保号状态机及媒体设备配额已全部集成；这些模块继续独立验收。

v0.4.4 见微 Emby · 维护与更新修复

- 备份恢复和升级先等待 Emby HTTP 服务就绪，再启动管理服务；活动日志只读请求对短暂网络故障有限重试，持续故障仍告警。
- 配置页移除重复 Git 更新，Release 部署关闭旧 Git 定时更新，统一使用版本与升级。
- 新增私有仓库只读 Token 设置：管理员密码校验、版本冲突检查、主机私有文件存储；下载保持摘要校验，跳转到 GitHub 资产站点时移除凭据。
- 后台降低标题与状态标签字重，取消中文伪粗体。
- Mini App 允许已使用的 webogram.org 客户端嵌入，管理页面仍禁止嵌入。

本次修复版本不代表保号、购买履约和完整机器人业务已全部完成；相关功能继续实施。
