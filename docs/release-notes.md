v0.2.0 安装与面板升级版

- 提供当前程序全量源码；内含实际构建的Twilight及固定OpenStrm源码、许可与全部部署工具。
- 提供Linux amd64完整分发包、源码包、前后端镜像、版本/兼容元数据与SHA256SUMS。
- 支持Debian/Ubuntu一键安装、一键卸载（默认保留数据）及显式清理。
- 管理后台新增“版本与升级”，通过固定操作的Unix socket执行器拉取最新正式Release。
- 升级先备份、验证来源与摘要、替换程序并检查健康；失败回退程序与镜像，保留数据库新写入。
- CI增加临时环境安装/升级/回退/卸载/重装检查；生产环境仅验证安装与升级。

域名、网盘和Bot由管理员后续绑定。v8.1方案中的定制保号、完整交易与24模块总控仍按docs/gaps.md开发，本版本不将这些未实现业务标为完成。
