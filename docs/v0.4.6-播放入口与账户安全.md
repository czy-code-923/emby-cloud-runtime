# v0.4.6 播放入口与账户安全

本版延续 v0.4.5 的 Telegram 原生面板与 Mini App，增加实际播放入口和账户自助安全操作。v0.4.5 的数据库 CI 因一条测试使用不存在的路由而中止；本版修正该测试，不跳过数据库校验。

- 站点与入口分别管理 Mini App、独立商店、Emby 播放三个域名的 DNS-01 证书、发布和续期。修改同一入口域名时可以保留已保存的 DNS 凭据；新域仍须在 Token 授权范围内。
- 公网 Mini App 与商店使用路由白名单，不开放后台、普通网页登录和管理员 API。原始服务端口继续仅绑定回环地址。
- 播放入口校验 Emby 用户令牌、本地账户状态和到期资格；禁止使用原生 Emby 服务器管理员令牌访问公网媒体 API。原生管理员继续通过 SSH 安全入口管理。
- 后台可设置普通用户、白名单、管理员的设备与同时播放流配额，并对单个用户覆盖。留空继承身份默认，0 为不限。设备配额需要启用受控播放入口；其他外部播放入口会绕过网关设备检查，应关闭或单独保护。
- 设备登记在数据库事务内执行，避免并发登录超额。用户通过安全码停用自己的旧设备，管理员可重置登记和停用记录。设备 ID 由客户端提供，不能将它当成不可伪造的硬件身份。
- 并发流写入 Emby 原生策略，保留其他策略字段。关闭曾由本系统管理的限制后，下一次网关访问会清除该用户的原生流限制。
- 新增 `/security`、`/password`、`/device_list`、`/device_release` 私聊命令和面板按钮。安全码采用密码散列存储，带验证频率限制；管理员重置须验证当前管理员密码。
- Mini App 增加安全码、改密、邮箱验证和设备名额管理；不支持 Mini App 的 Telegram 客户端可用原生命令。

## 部署顺序

见微实例的 Mini App 域名为 `jw.iczy.top`、播放域名为 `jwemby.iczy.top`、商店为 `jwshop.iczy.top`。先给新 Mini App 域名签发并发布证书、重新发布机器人菜单，再将旧域名发布为播放入口。不要让两个入口同时占用同一主机名。

Mini App 和商店可使用 Cloudflare 代理并配置 Full (strict)。播放域名使用 DNS only 或符合所用视频产品条款的专用代理；DNS only 不能隐藏服务器 IP。即使使用代理，也不能向已授权客户端保证域名永远不可见。

本版本不宣称自动追新下载或独立商店订单核款已经完成。商店 HTTPS 入口和商店业务分别验收；未完成业务前不要打开购买入口。完整安装包仍包含源码、前后端镜像、安装卸载入口和校验文件。
