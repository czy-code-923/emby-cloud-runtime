# v0.5 财务总控与会员操作

## 事故、钱包与退款

“财务与补偿”分别管理冻结/释放/调整、事故保护与日对账。冻结不减少总额，所有消费只用可用余额。每次提交保留理由、操作者、版本与幂等请求标识，流水追加，不能在页面改写旧账。

事故选择真实受影响用户、起止区间、保护期与拟补偿。已知服务器B模式采样中断超过90秒会生成三天保护事故，不补造观影秒数；管理员核实后可选择补偿天数/积分，或关闭事故。手动封禁不被解除，重叠事故保护分别保留。单次最多500人，可分批处理。

订单退款先撤回该来源尚未消费的权益并冻结卡码，再登记已在外部完成的全额退款引用。后来的独立权益保留；历史订单缺少来源、权益被未知方式修改时拒绝自动处理。退款不抹掉核销事实，也不自动转账。日对账以北京时间自然日比较已核实账面收退与实际收退，差异必须填写说明。目前登记全额退款，不支持支付接口自动退款或部分资金退款。

有冻结余额、已付款未交付/未使用卡码或待退款责任时，删除操作拦截。核款、发码、扣分和退款使用同一数据库事务，不维护第二套钱包。

## 24模块总控

总控包含24个稳定模块，与原有用户、邀请、商品、域名证书、迁移、任务、升级工作台互相链接。普通策略在总控创建草稿，预览变更前后与影响，再复核密码发布；当前配置变化会拒绝覆盖。环境变量覆盖显示为未在运行层生效。回滚仅限匹配版本的配置，不回滚订单、钱包、核销或媒体数据库。

执行超过两分钟仍无回执，可核对中断回执，记录当前配置版本后重新预览，不自动重放。Token、数据库连接和管理员授权字段不进入草稿日志。证书、真实核款、迁移及程序升级使用各自专用流程。

外部游戏奖励、异地数据服务、异地自动主备与追新下载并未因出现模块入口而接入。自动下载追新按约定后建。

## 收款与基础卡

“商店与订单”首次提供注册/续期/限期白名单的月、季、年共9项模板，默认停用且价格为0。管理员输入真实价格、库存和收款资料后启用，避免以虚构价格开业。

三类渠道是支付宝口令（默认选项）、支付宝个人静态收款码、微信个人静态收款码；赞赏码独立显示，不生成会员权益。图片可上传，付款口令加密保存，解密查看要求MFA及当前管理员密码。确认实际到账后只生成一次本人专属单次码，订单页、Mini App和机器人私聊回传同一张码；通知失败只重投，不再次扣分或发新码。

积分商店使用可用积分：月卡300/30天、季卡850/90天、年卡3000/365天。先确认扣分发码，再使用码叠加剩余权益。管理员和长期账户不可购买无用续期卡。白名单免活动保号；购买有效期内免活动保号，普通有限期账户只在剩余不足30天时选择活动方式。

## Bot 与 Mini App

Bot主面板以账户、服务状态、线路、设备、活动保号、积分商店、卡码和账户安全为主；公告、排行、收藏和媒体库放在Mini App，原命令仍保留。按钮编辑原消息/图片说明；需输入的用户名、卡码、安全码或密码用限时私聊引导。自定义宣传横图和推广位可分别开关。

Mini App的活动页合并签到、保号方式、签到动态、积分卡、本人最近20笔卡码和商店登录码。登录码有复制按钮。头像是当前用户圆头像，无用户头像时回退后台服务器图标，会员界面不显示源码仓库入口；许可证及源码获取义务保留于项目文档和管理员界面。

在线人数为近5分钟活动账号；观看人数为正在播放且非暂停的账号。故障显示不可用，不伪装为0。设备区分登录登记与在线播放，并显示配额；按Emby用户归属同步，停用要求安全码。已下发的第三方302直链未必能立即收回。

Emby不能反查原密码，线路页提供账号、地址、端口及受安全码保护的改密；不会保存可查询的明文密码。

## 多播放域名与部署

普通线路和白名单线路可配置多个HTTPS域名；在站点与入口逐个保存DNS凭据、申请、发布和续期。仅管理员与白名单可见并访问白名单线路；普通用户不能靠知道域名越权。客户端发现开放，媒体请求鉴权，Emby网页管理路径拒绝，原始端口只监听回环。

根权限维护工具支持只发布新增线路：

```bash
python3 scripts/publish-domains.py --zone YOUR_ZONE_ID --ip YOUR_VPS_IPV4 --account jw.iczy.top --shop jwshop.iczy.top --playback jwemby.iczy.top --extra-playback jwemby1.iczy.top --extra-playback jwembyb.iczy.top --only-extra --apply
```

该命令复用已保存且已同意正式ACME条款的DNS凭据，新增播放记录保持DNS-only。其他机器请替换为自己的域名和IP。不要把密钥写进命令。

播放Free/Pro/Business普通Cloudflare代理需要遵守其视频交付条件，不默认把播放流量开小黄云；当前方案接受源站IP可见。隐藏源站需要独立转发或适合视频的服务。

安装、数据保留卸载、正式Release升级及私有仓库凭据沿用README。支持Debian/Ubuntu Linux amd64。第二台真实VPS、真实收付款、媒体连续长播及跨到期观察仍须对应实机验证。
