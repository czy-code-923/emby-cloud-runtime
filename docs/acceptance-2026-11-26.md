## 实机结果与当前开关

- 账户域名的管理路径返回 403；独立商店返回 200；客户端发现请求返回 200，播放域名的网页入口返回 403，匿名媒体请求返回 401。这里验证的是入口与鉴权，不是影片已播放成功。
- 管理后台只经 SSH 本地转发登录，原始 13000、13001、18096 监听回环。没有以本机代理环境的 TCP 探测替代服务器监听与 HTTP 路径验证。
- 账户与商店继续使用 Cloudflare 代理；播放使用 DNS-only，源站 IP 可见为管理员已选择的部署方式。Emby 原生服务器管理员账户禁止通过公网播放网关使用；请使用普通媒体账户播放，原生服务器管理走 SSH 本地转发。
- 三个域名正式证书均已发布并核对原站 TLS；12 小时续期检查服务启用。域名可在后台修改，保存新值后仍需申请证书、显式发布才能生效。
- 每日签到与 A/B 保号已开启；管理员完成密码复核后页面显示“参与中”，Mini App 显示“服务器采样正常”。管理员和长期账户免活动保号，不能把它们作为普通用户 A/B 达标实例。同日重复签到返回原结果，没有重复入账。
- 邀请、迁移、推广位保持关闭；求片开启。商店停业，商品和订单为空，等待真实收款说明与定价。开关可由管理员调整，升级保留原选择。
- Emby 活动日志同步实际执行成功，当前新增 0 条；历史失败保留。原有 python3 的 TCP/80 与 sing-box 的 TCP/8080 在最终升级后仍监听。

## 复用部署命令

公共仓库一键安装：

```bash
curl -fsSL https://raw.githubusercontent.com/czy-code-923/emby-cloud-runtime/main/install.sh | bash
```

已安装主机一键卸载（默认保留配置、数据库、索引与备份，仓库改私有后也可使用）：

```bash
python3 /usr/local/lib/emby-cloud/manager.py uninstall
```

已有主机在“版本与升级”保存本仓库 Contents: Read 细粒度 Token 后，可继续使用同一升级按钮。私有新主机安装、域名发布、恢复与显式数据清理步骤见 [README](../README.md) 和 [operations.md](operations.md)。不要将 Token、Cloudflare 凭据或生产配置提交进仓库。
