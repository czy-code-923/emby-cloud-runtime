# v0.10.0 逐项验收清单

本清单区分已实现并回归、生产验证和仍依赖外部条件的事项。交易模拟使用独立PostgreSQL，不创建生产虚假付款，不替管理员确认真实收款。

## 本次生产验证状态

- 当前实际运行v0.9.2，HTTPS健康正常；管理员播放账号通过两条普通和一条白名单线路读取电影/剧集，原生owner仍为私有管理员。价格、支付渠道、用户权益及三个关闭的分区配置保留。
- v0.10新增代码的真实PostgreSQL测试及正式发布流程全部通过，9项资产齐全，1625个源码文件的发布包SHA-256校验通过，本机生产凭据未混入源码。**服务器尚未部署v0.10，不能把源码功能当成已在线启用。**
- v0.9.2临时白名单核验因只读旧版单地址字段而退出，在创建临时账号之前失败；v0.9.3及v0.10已修复多线路读取。**生产白名单到期后专属403/普通200仍待运行新版工具验证。**既有管理员能访问白名单线路，不等于已经验证白名单身份到期切换。
- SSH电脑控制窗口当前误识别为ChatGPT，已请用户重新打开ServerBox连接dmit-pro；恢复后先升级，再运行临时白名单测试并确认清理。没有盲输命令或改动真实订单。
- Mini App真实认证会话已核对管理员身份、30格签到、无需保号、积分保护、商店取码弹层、线路、设备折叠与发现栏目。Webogram容器折叠时临时展开验收，结束后恢复；这不等于所有原生客户端均已实测。

## 功能清单

| 项目 | 已实现及核对范围 |
|---|---|
| 管理登录 | 管理后台走本机SSH转发；普通用户走Telegram与Mini；原生owner用于私有Emby管理 |
| 管理员观影 | 平台管理员绑定独立非原生管理员播放账号；cc保留普通播放账号 |
| 播放鉴权 | 真实客户端登录令牌、用户ID、域名、设备、角色与到期权限校验；拒绝匿名、无效令牌、他人资源和公网网页管理 |
| 白名单 | 有效白名单可用普通及专属线路；到期恢复普通权限，不缓存旧角色；新增临时白名单真实HTTPS核验命令 |
| 设备与并发 | 管理员/普通/白名单默认配额及单用户覆盖；登录设备与播放会话、客户端名称/版本、配额和停用 |
| 注册与卡码 | 注册容量、单次/定向码、邀请码开关、群内redeem深链；已注册不重复创建；续期保留剩余时间 |

| 付费与白名单兑换 | 兑换影视续期后清除旧窗口授权；白名单独立期限与角色/配额同步；普通续期不增加白名单期限 |

| 积分商店 | 月/季/年卡，按钮预览确认、价格核验、幂等扣费、定向单次发码与核销；冻结不可消费；发码不提前取消A/B窗口 |
| 会员商店 | 注册/续期/白名单分类、推荐理由、商品增删/上下架、精确分币价格、选购后多渠道选择、独立底部赞赏 |

## 仍需外部条件或后续实施

1. 自动搜索PT资源、下载、追新和实际入库执行器，按用户决定后建。当前两个求片请求保留待处理，不伪造已下载或入库。
2. 音乐/有声小说/专属影视的真实媒体内容、对应库和独立域名，后续建设后再开启；当前只完成所需入口、卡码、积分及权限能力。不同Emby实例或纯文本小说阅读器尚未接入。
3. 真实影片长播、跨到期长期观察与302缺回传覆盖，需要真实影片和客户端回传；当前库内影片数量为0，不能声称已完成长播验收。
4. 支付平台自动到账查询、自动领支付宝口令红包、自动转账/退款未接入；人工实际核实收款后点击通过。已有真实配置保留，不凭空生成收款二维码或给未定价商品上架。
5. 真实第二台VPS安装、仓库实际改私有后的访问演练尚未执行；CI临时Linux环境已覆盖生命周期，凭据能力不等同于已做第二台实装。当前分发目标为Debian/Ubuntu Linux amd64。
6. Telegram X实体设备未进行原生测试；未支持`copy_text`的客户端只能使用兼容展示后长按复制或Mini App复制。原方案外部游戏积分、异地后端/主备及72小时资源观察等扩展仍未实施，不能把24模块配置入口视为已接入外部执行器。

公网播放域名继续使用用户接受的DNS-only方案，源站IP可见；保护措施是隔离原端口、HTTPS与账户/域名/库/设备鉴权，不承诺不可被扫描或绝对防攻击。
