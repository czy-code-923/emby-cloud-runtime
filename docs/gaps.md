# 方案核对与待完成事项（2026-11-26）

以正式 Release 和线上核验为准。历史失败的 v0.4.7 至 v0.4.9 不作为可安装版本；只有通过发布流水线的正式版本才会出现在安装器与后台更新中。

## 已实现并纳入验收

- 独立管理员网页、Telegram/Mini App 用户身份隔离；私有管理入口、播放/API鉴权、普通与白名单线路分级。
- 管理员/普通/白名单的默认设备数与播放流配额、单用户覆盖；安全码及本人设备释放。
- Cloudflare DNS-01 证书申请与12小时续期检查；账户、商店、播放三个独立 HTTPS 入口。播放域名仅供客户端，网页管理路径返回403。
- 公告、排行榜、Emby收藏与媒体搜索、签到、邀请与求片入口；邀请、求片、迁移和广告位可配置关闭。
- 机器人主面板按钮原消息内更新，普通客户端可直接使用命令；群内 redeem_ 链接复用资格校验，已开通不重复注册。
- 商店一次性登录码、商品与订单快照、库存/名额预占、实际流水人工核款、定向单次发码、未使用码冻结退款记录。核款与码消费并发互斥。
- A300积分/B1800秒、30天窗口单次自动续期、20天实际切换冷却、末72小时确认、3600签到奖励软上限、独立积分免保号卡及明确补救确认。默认关闭，启用和真实客户端观察另行验收。
- 版本包包含全量源码和镜像、安装/卸载入口与摘要。私有仓库升级凭据保存在主机私有文件；新机器安装支持短期 GitHub Token。

## 尚未全部完成或不能据此承诺

1. 真实客户端长时间观影、跨到期观察、302缺回传的采集覆盖；服务器采样只记有证据的连续播放，不凭活动日志推算达标。
2. 采集故障事故工单、批量补偿/暂停冻结的完整管理流程；事故不能被描述成用户活动不足。
3. 已核销付费权益按来源拆分退款、后续独立grant保护、完整跨站对账与财务通知中心。目前只支持未使用码冻结及外部退款记录，系统不自动转账。
4. 求片已有提交、审核、状态与通知；自动搜源、下载、追新、缺集补全、入库回传和异常删除熔断没有绑定下载器/追新系统。按用户决定留给后续独立系统。
5. 原方案24模块统一草稿发布、影响预览、全模块desired/applied和全模块回滚；游戏积分、异地数据接口、异地自动副本及72小时资源观察。
6. 跨VPS真实第二台安装、私有仓库真实访问切换尚未执行。CI临时环境覆盖安装、数据保留升级、回退、卸载、重装；当前分发支持Debian/Ubuntu Linux amd64。

## 使用边界

普通用户只使用Bot与Mini App。公网域名和客户端地址可以通过网络观察，不承诺隐藏地址本身；用户已选择播放入口DNS-only并接受源站IP可见。原始管理端口保持回环绑定，未知路径与网页管理入口拒绝。

商店默认停业，须管理员填写真实收款说明与价格后启用；广告位默认关闭，须填写真实广告内容。开启显示入口不代表已开通支付或自动采集。每次升级保留原配置，不覆盖用户主动开关。
