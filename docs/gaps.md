# v8.1 方案与本版本差距

本版本安装可运行的独立管理、用户业务底座、PostgreSQL、Emby 与回环入口。Twilight 提供账户/邀请/卡码、Bot 绑定、公告/求片/工单、系统配置、日志和迁移等上游能力；这些能力不等于本方案全部规则已经实现。

以下必须继续开发与验收，默认不得向用户承诺：

- 30天窗口 A300/B1800 秒自动保号、20天实际切换冷却、末72小时确认与24小时收尾、3600有机奖励上限及不可变账本。
- 24模块统一总控的草稿、影响预览、MFA发布、desired/applied回执与全模块回滚。
- 全媒体路由的对象权限/设备/同播准入、防扫库、跨入口真实用户限频与100人有界注册队列。
- 独立人工收款、份额预留、单次码、退款/对账/恢复水位和收款通知中心。
- 唯一媒体任务状态机、新集/缺集/异常删除熔断、观影可信采集和真实302多客户端验收。
- 游戏积分和异地数据接口。Cloudflare DNS-01、证书定时续期、账户/购买入口隔离发布已增加，真实签发仍需管理员提供域内 DNS Token 和明确接受 ACME 条款；发布升级执行器已实现正式Release校验、手动确认应用和程序回退，维护窗口/自动应用尚未实现。
- 完整隔离重建/异地恢复演练、异地自动复制及72小时资源观察；当前已实现本机停写加密快照、临时SQL库恢复与解密检查。

Telegram 不配置购买外链、现金价格或付费结账。付费码核销/商店不在这个版本中启用。
