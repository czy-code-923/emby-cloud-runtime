# 见微财务、事故与模块总控

本轮共享原有 PostgreSQL 状态 CAS，不建立第二套余额。钱包总额包含冻结，消费只读取总额减冻结；签到软上限仍按总额计算。调整、冻结、释放、补偿、积分码扣款和退款保留追加式流水，操作使用请求标识与版本检查。

## 事故与退款

事故先选择实际受影响的普通媒体用户、故障区间、最长30天保护期和拟补偿。开启保护暂停相关自动保号结算并保留限时播放；补偿或关闭需管理员确认，重复请求不重复延时或发分。人工封禁不会被解除，其他事故仍生效的保护不会被清除。

卡码核销记录权益来源及前后截止。退款先冻结未用码，已核销订单只撤对应来源尚未消费的时长，保留后来独立权益；缺失来源或存在无法解释的外部时长变化时拒绝自动减时长，交人工复核。这里不执行真实转账，管理员须核实实际退款并记录唯一引用。日对账区分账面、实际收退及差异，差异必须有理由。

## 24模块配置流程

`/admin/control` 对应24个稳定模块ID，链接已有专用工作台，避免复制核款、迁移、证书和升级实现。普通策略支持草稿、服务端校验、变更前后影响、版本绑定发布及配置回滚；secret、管理授权字段和数据库连接不进入草稿日志。配置回滚不回滚钱包、核销或交易数据库。环境覆盖明确显示未在运行层生效。

下载追新和外部游戏适配器未启用，不以模块入口存在冒充外部系统已接入。

## 管理端 API

以下要求独立管理员 Web 会话；财务写入与付款口令解密另外要求已启用MFA、当前管理员密码和显式操作意图。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v2/admin/finance` | 有界钱包、流水、事故、对账和日对账预览 |
| POST | `/api/v2/admin/finance/actions` | 版本及幂等检查后的钱包、事故、日对账提交 |
| GET | `/api/v2/admin/control` | 模块、无秘密字段及草稿记录 |
| POST | `/api/v2/admin/control/preview` | 生成有配置版本约束的校验草稿 |
| POST | `/api/v2/admin/control/apply` | 发布、撤回或配置回滚 |
| GET | `/api/v2/admin/play-rank/export` | 脱敏作品周榜CSV，不导出观看者身份 |
| POST | `/api/v2/admin/commerce/image` | 最大2MB PNG/JPEG收款码上传 |
| GET | `/api/v2/commerce/assets/:filename` | 仅公开指定收款图片，不公开上传目录 |

## 会员端 API

会员写入仍复用签名的 Mini App 身份、绑定UID、同源及意图检查，不能传其他UID；下面的读取均为private/no-store。

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/v2/miniapp/points` | 积分卡目录及可用/冻结余额 |
| POST | `/api/v2/miniapp/points` | 明确确认价格、幂等扣分及本人定向发码 |
| GET | `/api/v2/miniapp/orders` | 本人订单和待核销码 |
| POST | `/api/v2/miniapp/shop-code` | 商店专用一次性登录码 |
| GET | `/api/v2/miniapp/service` | 近5分钟在线人数、观看人数与播放流聚合 |
| POST | `/api/v2/miniapp/device-sync` | 按Emby用户归属同步本人登录设备，继续执行配额与停用限制 |
| GET | `/api/v2/miniapp/avatar` | 本人头像，不授予访问其他人头像的权限 |

机器人照片面板使用同一消息caption更新；第三方客户端继续支持纯文本命令。播放线路不回显原密码，提供真实账号、端口与安全码保护的改密流程。登录码按钮使用Telegram复制按钮，旧客户端可长按文本复制。

多播放入口分别保存域名、证书和发布版本，普通和白名单线路不共用可见权限。白名单域名同时在网关检查实际账号角色。`jwemby.iczy.top` 为客户端入口，网页管理保持拒绝。
